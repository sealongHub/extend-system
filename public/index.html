Extend System API Documentation

All API requests should be prefixed with /api. Timezone is set to Asia/Phnom_Penh.

Authentication API

POST /api/register

Register a new user.

POST /api/login

Login user and receive authentication token.

POST /api/logout

Logout user (requires authentication).

Categories API

GET /api/categories

List all categories.

ParameterTypeRequiredDescription
typestringNoFilter by income, expense, or saving
GET /api/categories/expense

List all expense categories.

GET /api/categories/income

List all income categories.

GET /api/categories/saving

List all saving categories.

GET /api/categories/{id}

Get a specific category by ID.

POST /api/categories

Create a new category.

KeyTypeRequiredDefault / Options
namestringYesCategory name
typestringYesincome, expense, saving
PUT /api/categories/{id}

Update a category (requires authentication).

DELETE /api/categories/{id}

Delete a category (requires authentication).

Incomes API (Protected)

GET /api/incomes

Fetch all income records with categories (requires authentication).

POST /api/incomes

Add a new income record (requires authentication).

KeyTypeRequiredDescription
amountnumericYesThe decimal amount
descriptionstringYesShort note
datedateYesYYYY-MM-DD
category_idintegerNoID from Categories table
PUT /api/incomes/{id}

Update existing income record (all keys optional in request body, requires authentication).

DELETE /api/incomes/{id}

Delete an income record (requires authentication).
